## コンセプト

> **「蝶が人間たちに奪われた自然を取り返す」**

人間によって汚染・破壊された大地を、プレイヤーが操る蝶が敵（人間・重機など）を撃破することで自然を回復させていく。  
単なる敵の撃破ではなく、**緑化度（自然の回復率）** という指標によって自分の貢献を実感できる点がこのゲームの核心。

---

## ゲームの流れ

```
タイトル画面
  └─ ゲーム開始
       └─ カウントダウン（4秒）
            └─ インゲーム（制限時間：約5分）
                 ├─ 敵を撃破 → 緑化度UP・ポイント獲得
                 ├─ Waveごとに敵が強化・多様化
                 └─ タイムアップ or プレイヤー死亡
                      └─ リザルト画面
                           └─ ランキング登録 → タイトルへ
```

---

## ゲームモード（Steam版）

| モード | 概要 |
|--------|------|
| **ランキングモード** | 制限時間内に最大緑化度を目指す。Steam Leaderboard に記録 |
| **Boss Rush モード** | ボスを連続撃破し、緑化度100%（完全回復）を目指す（開発予定）|

## 主な要素

### プレイヤー

- 上下左右に自由移動（キーボード WASD / ゲームパッド）
- スペース / ボタンで弾を発射
- 敵に触れるとダメージ（無敵時間あり）
- 武器は撃破数に応じて自動強化（発射方向が増加）

### 敵

| 種類 | 特徴 |
|------|------|
| NormalBoy | 直線追跡 |
| BigBoy | 慣性追跡（体が大きい）|
| OldMan | 予測追跡（プレイヤーの進行先を読む）|
| Excavator | 円弧移動（重機）|

### 緑化システム

- 敵撃破でプレイヤー周辺のタイルが草地に変化
- アイテム「範囲緑化」で3×3エリアを一括緑化
- 緑化度（0〜100%）＝緑化済みタイル数 ÷ 総タイル数

### アイテム

| アイテム | 効果 |
|---------|------|
| SpeedBoost | 一定時間、移動速度上昇 |
| ScoreMultiplier | 一定時間、獲得ポイント倍増 |
| AreaGreenify | 一定時間、敵撃破時に周囲3×3を緑化 |

### Shop（開発予定）

- タイトル画面からアクセス
- ゲーム内ポイントでキャラスキン・弾スキンを購入
