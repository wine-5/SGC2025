# 仕様書 — UI システム

**対象スクリプト**: `UI/` 以下全て、`HPBarController.cs`  
**最終更新**: 2026-06-07

---

## 概要

各シーンの UI を管理する。インゲーム UI・リザルト画面・ランキング・名前入力・ポーズ・設定を含む。  
共通基底クラス `UIBase` にフォーカス管理・シーン遷移ボタン処理をまとめている。

---

## UIBase（共通基底クラス）

すべての主要 UI クラスが継承する基底クラス。

| 機能 | 内容 |
|------|------|
| フォーカス自動設定 | `Start()` で `firstSelect` オブジェクトに UI フォーカスを設定（ゲームパッド対応） |
| ボタン処理 | `OnClickRestart()`・`OnClickBackTitle()`・`OnClickExit()` を共通提供 |
| スコアカウントアップ | `ScoreCountUp(elapsed, duration, targetValue)` → 時間補間値を返すユーティリティ |

---

## InGameUI

インゲーム中に表示される HUD 全体を管理する。

### 表示要素

| 要素 | 内容 |
|------|------|
| スコアテキスト | 現在のトータルスコア（フラッシュ・パルスアニメーション付き）|
| 残り時間テキスト | `InGameManager.RemainingGameTime` を表示 |
| Wave テキスト | 現在の Wave 番号（アニメーション付き）|
| 領地ゲージ | `Image.fillAmount` で緑化度（0〜1）を表示 |
| 緑化率テキスト | 緑化度 % を数値表示 |
| カウントダウンテキスト | ゲーム開始前のカウントダウン（パルスアニメーション付き）|

### スコアポップアップ

- 敵撃破・タイル緑化時にワールド座標でポップアップを表示
- `EnemyEvents.OnEnemyScoreAdded`・`GroundEvents.OnGreenScoreAdded` を購読
- `PopupScoreUI` を Pool 管理（上方向にフロートしながらフェードアウト）

### 購読イベント

| イベント | 処理 |
|---------|------|
| `InGameManager.OnCountDownFinished` | カウントダウン表示を終了 |
| `WaveManager.OnWaveChanged` | Wave テキストを更新 |
| `EnemyEvents.OnEnemyScoreAdded` | スコアポップアップ生成 |
| `GroundEvents.OnGreenScoreAdded` | スコアポップアップ生成 |

## ResulltUI（※ typo：Result の l が2つ）

リザルト画面。スコアをフェーズ別にカウントアップ表示する。

### 表示フェーズ

```
Init → GreeningRate → EnemyKillScore → GreeningScore → TotalScore → HighScore → End
```

各フェーズで対応するスコアが数値アニメーションで表示される。

### ランキング登録フロー

```
ResulltUI（HighScore フェーズ）
  └─ NameInputUI を表示
       └─ プレイヤーが名前を入力して決定
            └─ NameInputUI.Submitted 発火
                 └─ RankingUI.UpdateScore() でランキング再描画
```

## NameInputUI

| 仕様 | 内容 |
|------|------|
| 最大文字数 | 5文字（`MAX_NAME_LENGTH = 5`）|
| 入力方式 | `TMP_InputField` |
| 決定 | 決定ボタン押下で `RankingManager.AddScore()` を呼び出し |

## RankingUI

- `RankingManager.GetRanking()` からデータを取得
- 名前・スコア・緑化率を最大 3 件表示
- `UpdateScore()` メソッドで再描画可能

## TitleUI

- `Start()` で `AudioManager.PlayBGM(BGMType.Title)` を呼び出す

`UIBase` のみ継承。追加実装なし（リスタート・タイトル戻りボタンを `UIBase` から利用）。

## SettingsUI

音量設定パネル。

| 要素 | 内容 |
|------|------|
| マスター音量スライダー | `AudioManager.masterVolume` に即時反映 |
| BGM 音量スライダー | `AudioManager.bgmVolume` に即時反映 |
| SE 音量スライダー | `AudioManager.seVolume` に即時反映 |
| 閉じる | `UIInputManager.OnCancelPressed` でパネルを閉じる |

## HPBarController

> **NOTE**: スクリプトルート直下（`Scripts/HPBarController.cs`）に孤立している。リファクタリング時に `UI/` へ移動予定。

プレイヤー・敵の HP をバーとして表示するコンポーネント。

| パラメータ | 内容 |
|-----------|------|
| `entity` | 対象の GameObject |
| `isPlayer` | true = プレイヤー用、false = 敵用 |
| `offsetFromPlayer` | HP バーのエンティティからのオフセット |

### 動作

- 毎フレーム対象エンティティの位置に追従（`Update`）
- プレイヤーの場合は `PlayerDataProvider` から自動取得
- `currentHealth / maxHealth` を `transform.localScale.x` に乗算してバー幅を変化

---

## UIFocusHelper（ユーティリティ）

ゲームパッド対応のためのフォーカス制御。

| メソッド | 処理 |
|---------|------|
| `SetFocus(GameObject)` | `EventSystem.SetSelectedGameObject` |
| `ClearFocus()` | 選択解除 |
| `RestoreFocus(GameObject)` | 指定要素へフォーカス復元 |

---

## PopupScoreUI

| 動作 | 内容 |
|------|------|
| 表示 | `Initialize(score, position, onComplete, isBoostActive)` で初期化 |
| アニメーション | 上方向にフロートしながらフェードアウト |
| 完了 | `onComplete` コールバックを呼び出してプールに返却 |

---

## SceneChangeButtonHandler

ボタンに付けるだけでシーン遷移できる汎用コンポーネント。

- Inspector で `targetScene`（`SceneName` enum）を指定
- `ChangeScene()` → SE 再生後 `SceneController.I.LoadScene(targetScene)`

---

## 依存関係

```
InGameUI
  ├─ InGameManager（カウントダウン・残り時間）
  ├─ WaveManager（Wave 番号）
  ├─ ScoreManager（スコア値）
  ├─ GroundManager（緑化度）
  ├─ EnemyEvents（スコアポップアップ）
  └─ GroundEvents（スコアポップアップ）

ResulltUI
  ├─ ScoreManager（スコア値）
  ├─ RankingManager（ランキング登録）
  ├─ NameInputUI（名前入力）
  └─ RankingUI（ランキング表示）
```
